## Featured Project — SavingsBook

Ứng dụng quản lý tiết kiệm cá nhân, phát triển song song trên hai nền tảng với cùng một trải nghiệm sản phẩm, tuân theo chuẩn thiết kế của từng hệ điều hành.

### [SavingsBook-iOS](https://github.com/karsirdev/SavingsBook-iOS) ![Status](https://img.shields.io/badge/status-in_progress-A78BFA?style=flat-square)

- **Design:** Figma-first, dual-theme system (Light / Dark) với bộ design token riêng
- **Architecture:** MVVM, tổ chức theo feature module
- **Auth flow:** Welcome → Login → Register → OTP Verification
- **Components:** `PrimaryButton`, `SBTextField`, `PasswordField` — tái sử dụng toàn app
- **Workflow:** Conventional Commits, `git pull --rebase`

`Swift` `SwiftUI` `MVVM` `Figma`

### [SavingsBook-Android](https://github.com/karsirdev/SavingsBook-Android) ![Status](https://img.shields.io/badge/status-in_progress-A78BFA?style=flat-square)

- **Design:** Material Design 3, adaptive theming
- **Architecture:** MVVM, Jetpack Compose
- **Auth flow:** `WelcomeScreen` ✓ · `LoginScreen` (đang phát triển)

`Kotlin` `Jetpack Compose` `Material 3`

## Engineering Principles

- **Design system trước, UI sau** — token và component tái sử dụng thay vì copy-paste.
- **Separation of concerns** — MVVM, View không chứa business logic.
- **Idiomatic code** — Swift theo Swift, Kotlin theo Kotlin, không port máy móc.
- **Commit có ý nghĩa** — Conventional Commits, lịch sử rõ ràng, dễ review.
